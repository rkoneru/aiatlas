Build an agent in Claude, without code

You can set up a capable, agent-like assistant in the Claude app with no code: a project holds its instructions and knowledge, connectors give it access to your apps, skills teach it repeatable workflows, and scheduled tasks let it run on its own. Use the worksheet below to write its instructions.

Viral "build an agent in 10 minutes" guides often describe screens that don't exist. These steps follow Claude's help center as of November 2026; menus can move, so check support.claude.com if something looks different.
