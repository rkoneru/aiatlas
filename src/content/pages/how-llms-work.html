How LLMs work, from prompt to response

A decoder-only transformer turns your prompt into tokens, then vectors, runs them through stacked layers of causal self-attention and feed-forward networks, and predicts one token at a time. Step through the pipeline, then try each stage on live text.

1 · Tokenization → token IDs

Illustrative only. Real tokenizers (BPE, SentencePiece) learn subword pieces from data, so common words are one token and rare words split into several. The IDs here are made up but consistent: the same piece always gets the same ID.

2 · Embedding + position

X = Et + Ep

Each token ID looks up a row in the embedding matrix E ∈ ℝV×d (vocabulary × model width). Positional information, learned or RoPE, is added so the model knows word order. Similar meanings end up as nearby vectors. Try cosine similarity →

FFN(x) = σ(xW1 + b1)W2 + b2

After attention, each token goes through a feed-forward network: expand to about 4× the width, apply a non-linearity (GELU, SwiGLU…), project back. LayerNorm (γ·(x−μ)/√(σ²+ε) + β) and residual connections keep the deep stack stable.

3 · Causal self-attention

Attention(Q,K,V) = softmax( QKT√dk + M ) V
Click a row to see where that token "looks".

Weights are illustrative, not from a real model. In multi-head attention, several heads run this in parallel, each learning a different relationship (syntax, coreference, position…). Their outputs are concatenated and projected back.

4 · Next-token prediction & sampling

P(wi | context) = exp(zi / T)Σj exp(zj / T)

Context: "How do I prepare for a PM interview?" → first token of the answer.

Low temperature means sharp, predictable choices; high temperature means flatter, more creative ones. Top-k removes the long tail. The chosen token is appended and the whole process repeats.

5 · Training objective

ℒ = − 1n Σt=1n log P(xt | x1, …, xt−1)

Pre-training is just next-token prediction with cross-entropy loss, over trillions of tokens, optimized by gradient descent (Adam). Capabilities like translation or coding emerge from doing this at scale. Instruction-following comes later, from fine-tuning. See the LLM engineering roadmap →
