5 · Building agent systems

Harness, loop & graph engineering

Three ways to build agent systems: a harness to empower one agent, a loop to refine output, a graph to handle complex work. Most production systems nest them, for example a graph whose nodes are harnessed agents with internal loops.

Loop simulator

An evaluator–optimizer loop: draft, score, refine. Set the quality bar and the iteration budget. A good stop condition is the difference between self-correction and an infinite loop.

Which pattern fits?

Harness engineering: from powerful models to reliable results

A harness is the control system around a model: guides that raise the odds of a good first attempt, sensors that let the agent see and correct what it did, and state that lets work survive the end of a context window. The same model can produce broken or working software depending on what surrounds it.
