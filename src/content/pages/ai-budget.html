Budgeting rules of thumb

Fund platforms once

Shared gateway, RAG, evals and observability, charged back or centrally funded, so use cases don't each rebuild them.

Stage-gate use cases

Release money in tranches: discovery, pilot, scale. Each gate needs measured results.

Budget for change

Training, champions and process redesign often decide whether the technology pays back.

Expect token prices to fall

Model prices per token have fallen quickly while usage grows. Plan on volume growth, not a fixed bill.

Keep contingency

10–15% for model changes, new compliance duties and surprise volume.

Show unit cost

Cost per resolved ticket, per document or per user is what finance can compare with today's process.
