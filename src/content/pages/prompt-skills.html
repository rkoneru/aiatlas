Working with AI

Prompt vs Project vs Skill

Same AI, three levels of setup. A prompt is instructions typed every time. A project holds files and instructions that every chat inside it remembers. A skill teaches a process once, and it loads automatically when the task comes up.

PromptProjectSkill
The gistYou type instructions every time; you repeat yourself next time.You upload files and write instructions once; every chat in the project has them.You teach a process once; it activates when the task matches.
SetupZeroAbout 5 min: create, upload, write instructionsAbout 15 min: describe the process (a skill-creator can interview you)
Activates automatically?NoOnly inside that projectYes, when the task matches its description
Workflow stepsOnly if you list them every timeOnly if written into the instructionsThat's exactly what a skill is: a packaged step-by-step process
Token costLong prompts every timeContext is loaded per chatOnly a short description sits in context until needed
Across conversationsGone when you start a new chatEvery chat inside the projectAny conversation where skills are available
The vibeTelling a stranger how to do your job every morningGiving a new hire a binder on day oneTraining an employee once; they follow it from then on

Which one do you need?

The 3-conversation rule: if you've typed the same instructions more than three times, that's a skill waiting to be built. The best setup uses all three: quick tasks as prompts, deep work in a project, recurring processes as skills. See also skills in Claude Code. Where skills are available and how they're installed depends on your plan and app, so check your settings.
