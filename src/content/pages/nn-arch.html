Models · Deep learning

Neural networks: architectures & learning

Different data has different structure, and each architecture builds that structure in. CNNs assume nearby pixels matter together, RNNs read sequences in order, transformers let every token look at every other token, and state-space models compress long sequences into a running state. Step through a CNN, then compare the families.

The four families

CNN · convolutional

Shared local filters

Small filters (say 3×3) slide across an image and detect edges, then textures, then parts, then objects as layers stack. Pooling shrinks the map. Weight sharing makes CNNs efficient and translation-tolerant. Still the backbone of many vision, medical imaging and audio front-ends.

ResNetEfficientNetYOLO
RNN · LSTM · GRU

A running memory

Process one step at a time, carrying a hidden state forward. LSTMs add gates to keep information over longer spans. Training is sequential (slow on GPUs) and long-range memory fades, which is exactly the problem attention solved.

LSTMGRUseq2seq
Transformer

Attention over everything

Every token attends to every other token in parallel, so training scales on GPUs and long-range dependencies are easy. The cost is quadratic in sequence length. Powers LLMs, vision transformers (ViT), speech and multimodal models. See How LLMs work.

GPT · ClaudeBERTViT
State-space models

Linear-time sequence models

Mamba-style SSMs keep a fixed-size state updated by selective, input-dependent rules. They run in linear time with constant memory per token, which suits very long sequences. Many recent models are hybrids that interleave SSM layers with a few attention layers.

Building blocks you'll see everywhere

Activations

ReLU, GELU, SiLU/SwiGLU add the non-linearity that lets stacked layers learn curves, not just lines.

Normalization

BatchNorm (CNNs) and LayerNorm/RMSNorm (transformers) keep activations in a stable range so deep networks train.

Residual connections

Add each block's input to its output. Gradients flow through hundreds of layers instead of vanishing.

Dropout

Randomly zero activations during training to reduce co-adaptation and overfitting. Turned off at inference.

Pooling & stride

Downsample feature maps so later layers see a wider area for the same cost.

Embeddings

Lookup tables that map discrete tokens or IDs to dense vectors the network can work with.

How neural networks learn

Every model, from a spam filter to a frontier LLM, learns the same way: make a prediction, measure the error, work out how each weight contributed (backpropagation), and nudge every weight a little downhill (gradient descent). Walk one training step, then try the learning-rate playground.

Gradient descent playground

The loss surface is a long, narrow valley. Start at the dot and take steps against the gradient. Too small a learning rate crawls; too large overshoots and diverges. Momentum helps cross the valley floor.

The mechanics

Gradient descent

Downhill, one step at a time

The gradient says which direction increases the loss fastest; step the other way. Mini-batch SGD estimates the gradient from a small batch, which is noisy but cheap. Momentum smooths the path. Adam/AdamW adapts the step per parameter and is the default for transformers. A learning-rate schedule (warm-up, then cosine decay) matters as much as the optimizer.

Backpropagation

Blame assignment by the chain rule

After the forward pass computes the loss, the backward pass applies the chain rule layer by layer, from the output back to the input, to get every weight's gradient in one sweep. Frameworks (PyTorch, JAX) do this automatically with autograd. Problems: gradients can vanish or explode in deep networks; residual connections, normalization and gradient clipping fix most of it.

Batches, epochs & scale

How much data per step

An epoch is one pass over the data. Larger batches give smoother gradients and better GPU use but need higher learning rates and can generalize slightly worse. LLM pre-training usually sees each token about once, measured in tokens rather than epochs, and is spread across thousands of GPUs with data, tensor and pipeline parallelism.

Mixed precision & checkpoints

Making training affordable

Train in bf16 or fp8 with fp32 master weights to halve memory and speed up math. Gradient checkpointing trades compute for memory by recomputing activations. Save checkpoints often: long runs fail.

Positional encoding

Why it's needed

Attention treats its input as a set. Without position information, "dog bites man" and "man bites dog" look identical.

Absolute & learned

The original transformer added sine waves of different frequencies; GPT-2 learned one vector per position. Both struggle beyond the trained length.

RoPE (rotary)

Rotate query and key vectors by an angle proportional to position, so attention scores depend on relative distance. Used by most modern LLMs. Scaling tricks (position interpolation, YaRN) stretch the rotations to extend context length.

Symbolic AI vs connectionism

Symbolic (GOFAI)

Rules and logic

Hand-written knowledge: expert systems, logic programming, planners, knowledge graphs. Precise, explainable and verifiable, but brittle and expensive to build.

Connectionist

Learned representations

Neural networks learn patterns from data. Robust to messy input and broad, but statistical, hard to inspect, and prone to confident mistakes.

Neuro-symbolic, today

Both together

Modern systems combine them: an LLM plans and talks, while code interpreters, solvers, ontologies, schemas and rule engines provide exactness. See self-evolving ontology and JEV vs LLM.
