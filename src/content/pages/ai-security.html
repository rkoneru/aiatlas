AI security: OWASP Top 10s & supply chain

The OWASP GenAI Security Project maintains two lists every team building with LLMs should know: the Top 10 for LLM Applications 2026 and the Top 10 for Agentic Applications. Read them together once a model can use tools. Step through the attack surface, then check which risks your controls cover.

OWASP Top 10 for LLM Applications 2026

#Risk2025 rankWhat it means
LLM01Prompt Injection1Instructions hidden in input or retrieved content hijack the model. Higher stakes now that agents reach private data and take actions.
LLM02Sensitive Information Disclosure2Leaking PII, secrets or other users' data, including RAG retrieval that ignores permissions.
LLM03Excessive Agency6Too many tools, permissions or autonomy for the task. Up three places as models gained operational authority.
LLM04Supply Chain3Tampered weights, unsafe model formats, malicious packages and name-squatting.
LLM05Data and Model Poisoning4Corrupted training, fine-tuning or RAG ingestion data that plants backdoors or bias.
LLM06Unbounded Consumption10Runaway cost or denial of service from token floods and agent loops.
LLM07Misinformation9Confidently wrong output that people or automated systems act on.
LLM08Hidden Context Exposure7Formerly System Prompt Leakage; now also tool schemas, policies and workflow rules.
LLM09Vector and Embedding Weaknesses8Attacks on retrieval: poisoned embeddings, inversion, cross-tenant leakage.
LLM10Improper Output Handling5Passing model output unchecked into browsers, shells, SQL or other systems.

Control coverage check

Tick the controls you have in place. Each risk turns green when at least one strong control covers it.

Model & agent supply chain

Safe formats

Prefer safetensors over pickle-based checkpoints, which can execute code when loaded.

Provenance & signing

Pin model versions by hash, verify signatures, and pull only from trusted registries.

AI bill of materials

Inventory models, datasets, prompts, agents, tools and MCP servers, like an SBOM for AI.

Vet MCP servers & plugins

Review tool descriptions (they're prompts too), pin versions, and watch for silent updates.

Dependency hygiene

Lock package versions; watch for typosquatted AI libraries and hallucinated package names.

Data lineage

Know where training, fine-tuning and RAG data came from, and who can write to it.

Sources: OWASP GenAI LLM Top 10 (2026 edition published August 2026) and OWASP Top 10 for Agentic Applications (December 2025). Rank changes summarized from the Cloud Security Alliance's comparison. See also AI guardrails.
