FDE playbook

Forward-deployed engineers sit with the customer and take an AI solution from a fuzzy problem to production value. This playbook gives each phase a template you can fill in, save, and export as Markdown: discovery, solution design, success plan, go-live and handoff.

FDE principles

Problem before platform

Start from the customer's metric and process, not the product's features. Map the as-is workflow first.

Baseline on day one

Measure today's handle time, error rate or cost before building anything, or the value story can't be told.

Ship thin, then widen

One intent, one channel, one team, live in weeks. Expand from evidence.

Evals are the spec

Agree the golden set and pass bar with the customer; it settles "is it good enough?" debates.

Design for handoff

Runbooks, dashboards and ownership from the start, so the customer can run it without you.

Harvest patterns

Every deployment should leave behind a reusable template, connector or eval set for the next one.
