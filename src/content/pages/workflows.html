LLM workflow patterns

Design smarter pipelines, get better results. Five composable patterns: chain, parallelization, routing, orchestrator–workers and evaluator–optimizer. In these, your code (or the orchestrator) controls the flow. Reach for a fully autonomous agent only when none of them fit.

Which pattern fits?

These are the workflow patterns described in Anthropic's Building effective agents guide. They compose: a router can send a request into a chain, and a chain's step can be an evaluator–optimizer loop.
