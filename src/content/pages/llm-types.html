8 types of LLMs used in AI agents

Different architectures, same goal: smarter agents. LLMs power the brain of an agent, but "LLM" now covers very different designs. Pick a type to walk through how it works.

Which type for which agent job?

These categories overlap. A frontier model can be a GPT-style transformer, use MoE internally, reason like an LRM and see images like a VLM, all at once. Treat the eight as lenses, not exclusive boxes.
