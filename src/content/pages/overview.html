An LLM generates text. RAG gives it knowledge. An agent lets it act. MCP standardizes how it reaches tools. A2A lets agents work with other agents. Walk the end-to-end request below, then open each layer.

The ladder

0 · LLM

Understands & generates

Trained on massive text, predicts the next token. Knows only what it was trained on.

 1 · RAG

More context

Retrieves domain or fresh data before answering. Fewer hallucinations, with citations.

 2 · Agent

More autonomy

Plans, calls tools, observes, adjusts. Closed-loop execution in real systems.

 3 · MCP

More connections

One standard protocol for tools, resources and prompts, usable from any host.

 4 · A2A

More collaboration

Agents discover, delegate to and coordinate with other agents across teams and vendors.
