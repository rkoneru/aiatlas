Observability & on-call for AI agents

You can't fix what you can't see. Trace every request end to end, from the user message through retrieval, model calls and tools, using a shared vocabulary so any backend can read it. OpenTelemetry's GenAI semantic conventions provide that vocabulary; they moved to their own repository in June 2026 and are still marked Development, so pin a version.

On-call runbook

1 · Triage

Is it the provider, a tool, retrieval or a change we shipped? Check the provider status page, recent deploys and prompt or model changes.

2 · Contain

Fail over to a backup model, disable the failing tool, switch to a safe fixed flow, or route to people. Have these switches ready before launch.

3 · Learn

Add the failing conversations to the regression set, fix, and write a short post-incident note. See the incident register.
